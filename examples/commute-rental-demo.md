# 通勤租房：虚构场景演示

此文件展示输入和产出形式，不是实时找房结果。城市、办公楼、小区、车站及路线均为虚构或合成数据，链接使用 `.invalid` 域名，无法定位真实个人办公地点。

用户输入：“我在xx市，办公地点在xx办公楼（虚构地址），通行时间需要控制在一个小时以内（公共交通和电动车），价格在2500以内，独卫，需要有电梯。”

需求：月租≤2500、两种方式各≤60分钟、独卫/电梯；默认all、工作日高峰、月租口径。实际任务需补充真实办公楼与入口，具体到岗时间、租赁类型、杂费仍是缺口。住所不自动限定在办公地点所在行政区。

## 执行

```powershell
.\.venv\Scripts\python.exe scripts/find_rentals.py --input examples/demo-input.json --output-dir reports/demo --as-of 2026-10-19T09:00:00+08:00
```

`--as-of` 仅用于离线样例回放，真实查询省略，按当前时间判断时效。输出report.json、report.md、listings.csv，包括全部唯一候选、三态结果、推荐、来源和审计。

演示含9条合成输入，去重后8套：符合2、待核实4、不符合2。覆盖缺电梯证据、超预算、电动车超时、搜索摘要、过期证据、重复房源和同小区不同房间。

## 使用边界

实际运行Skill时需要宿主检索真实房源、定位办公楼、分别查询路线并留证据。不能照搬本示例推荐或将其统计称为真实挂牌结果。个人地址、坐标与任务报告留在本地任务目录，不提交到公开仓库。
