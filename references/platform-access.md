# 平台接入与失败降级

最后更新：2026-10-19。

本包没有平台爬虫、合作接口或账号授权。旧稿记录过Wellcee/咕咕/安居客页面差异，但无随包日志或原始证据，**不作为本版已验证可用性**。不要宣称某平台“无反爬”“永久可抓”或按房东身份断言可信度。

使用授权接口或宿主允许读取的公开页面。可考虑目标城市适用的平台，当轮记录是否可读、字段与授权限制。列表成功而详情失败时可用列表明确字段，不因此访问隐藏接口、轮换代理或破解验证码。

从真实链接进入，核验站名与条件，按自然分页覆盖；不扫描连续站号/房源ID。列表筛选参数不是每套设施证明。列表/详情冲突需复核，不能静默取较低价。

`coverage[]` 记录平台、查询、范围/页数、时间、数量、失败原因。“已采集N条”需N条记录支撑，跨页汇总后输出一次。

| 数据层 | source.kind | 使用 |
|---|---|---|
| 实开详情 | detail | 记录该套明确字段及短证据 |
| 实开列表 | list | 未出现设施/可租状态为未知 |
| 用户可追溯证据 | user_evidence | 无公开来源时进入待核实，区分自述与现场核验 |
| 搜索摘要 | search_snippet | 仅线索，不进严格推荐 |

不采集联系人姓名、手机号、微信、凭据或整页HTML。输出采用允许字段，代码仅提供常见联系方式脱敏与CSV公式转义，不能保证识别任意个人信息，采集端仍须最小化。

降级：授权接口/可读详情 → 可读列表 → 用户证据 → 检索计划与缺口。验证码/登录墙/限流按平台要求处理；无证据就空结果，不编造补数。

公开可见不等于允许批量再发布。外部规模服务前确认平台条款、数据授权、展示字段、下架机制、速率与缓存期限。MIT只覆盖原创代码/文档，不覆盖第三方挂牌内容。
